ARC MOTHERBOARD | EASYEDA TO STM32 NET MAP
=========================================

U1 is the STM32H723ZGT6 in LQFP-144 on sheet 07.
Find the GPIO name on the symbol and check the physical pad in brackets.
Example: ETH_REF_CLK -> PA1 [35] means put ETH_REF_CLK on MCU pad 35.
Reuse the exact names below for the cross-sheet connections. AF identifies
the firmware alternate function. TX/RX directions are from the motherboard.
The saved EasyEDA project has these labels on sheets 08 and 09. Sheet 07
still needs the wiring. The map gives the draft destinations to wire there.
Put the name on the wire and confirm that the actual net has that name
in EasyEDA's net panel. Check each endpoint after adding the sheet 07 port.


08 | ETHERNET TO ORIN
---------------------
ETH_REF_CLK       -> PA1  [ 35]  AF11  50 MHz input from LAN8742A pad 14
ETH_MDIO          -> PA2  [ 36]  AF11  LAN8742A pad 12, bidirectional
ETH_MDC           -> PC1  [ 27]  AF11  LAN8742A pad 13
ETH_CRS_DV        -> PA7  [ 43]  AF11  LAN8742A pad 11
ETH_RXD0          -> PC4  [ 44]  AF11  LAN8742A pad 8
ETH_RXD1          -> PC5  [ 45]  AF11  LAN8742A pad 7
ETH_TX_EN         -> PG11 [126]  AF11  LAN8742A pad 16
ETH_TXD0          -> PG13 [128]  AF11  LAN8742A pad 17
ETH_TXD1          -> PB13 [ 74]  AF11  LAN8742A pad 18
PHY_NRST          -> PE2  [  1]  GPIO  Active-low output to LAN8742A pad 15

PE3 [2] is reserved for PHY_IRQ. The PHY's pad 14 supplies REF_CLK in this
design, so leave PHY_IRQ unwired and read link state over MDIO.


09 | MOTOR AND STEERING CONNECTORS
----------------------------------
DRIVE_FL_TX       -> PA9  [101]  AF7   USART1 TX, U3
DRIVE_FL_RX       -> PA10 [102]  AF7   USART1 RX, U3
DRIVE_FR_TX       -> PD5  [119]  AF7   USART2 TX, U11
DRIVE_FR_RX       -> PD6  [122]  AF7   USART2 RX, U11
DRIVE_BR_TX       -> PE8  [ 59]  AF7   UART7 TX, U12
DRIVE_BR_RX       -> PE7  [ 58]  AF7   UART7 RX, U12
DRIVE_BL_TX       -> PD1  [115]  AF8   UART4 TX, U13
DRIVE_BL_RX       -> PD0  [114]  AF8   UART4 RX, U13
VESC_COMM_TX      -> PG1  [ 57]  AF11  UART9 TX, U14 to the VESC RX
VESC_COMM_RX      -> PG0  [ 56]  AF11  UART9 RX, U14 from the VESC TX
STEER_UART_TX     -> PE1  [142]  AF8   UART8 TX, U16
STEER_UART_RX     -> PE0  [141]  AF8   UART8 RX, U16
STEER_PWM         -> PB7  [137]  AF1   TIM17_CH1N through 33 ohms, U15 pin 3

BR and BL are called RR and RL in the earlier guide. Use the BR and BL
spellings above on both sheets to match the EasyEDA connectors.
U14 contacts are 1 GND, 2 VESC_COMM_TX, 3 VESC_COMM_RX, 4 unused.
For PWM, wire PB7 -> STEER_PWM_MCU -> 33 ohms -> STEER_PWM -> U15 pin 3.
A50S_ESTOP_N goes to the independent stop circuit on sheet 04.
U15 pin 1 has a ground wire and a no-connect flag in the saved drawing.
Remove the flag. Route pin 1 SERVO_GND and pin 2 SERVO_VPLUS to the rated BEC.
Bond SERVO_GND to board GND at the power-return connection for the PWM reference.

09 | TIME-OF-FLIGHT SENSORS
-------------------------
TOF_1_SCL         -> PB8  [139]  AF4   I2C1 clock, U25
TOF_1_SDA         -> PB9  [140]  AF4   I2C1 data, U25
TOF_2_SCL         -> PB10 [ 69]  AF4   I2C2 clock, U26
TOF_2_SDA         -> PB11 [ 70]  AF4   I2C2 data, U26
TOF_3_SCL         -> PA8  [100]  AF4   I2C3 clock, U27
TOF_3_SDA         -> PC9  [ 99]  AF4   I2C3 data, U27
TOF_4_SCL         -> PF14 [ 54]  AF4   I2C4 clock, U28
TOF_4_SDA         -> PF15 [ 55]  AF4   I2C4 data, U28

TOF_1_XSHUT       -> TBD          Optional shutdown output, U25
TOF_1_GPIO1       -> TBD          Optional interrupt input, U25
TOF_2_XSHUT       -> TBD          Optional shutdown output, U26
TOF_2_GPIO1       -> TBD          Optional interrupt input, U26
TOF_3_XSHUT       -> TBD          Optional shutdown output, U27
TOF_3_GPIO1       -> TBD          Optional interrupt input, U27
TOF_4_XSHUT       -> TBD          Optional shutdown output, U28
TOF_4_GPIO1       -> TBD          Optional interrupt input, U28

Each ToF has its own I2C bus. For the polled setup, leave XSHUT and GPIO1
unwired at the MCU. The sensor board already pulls XSHUT high.
Contact order on both boards is 1 GND, 2 +3V3, 3 XSHUT, 4 GPIO1, 5 SDA, 6 SCL.
FIX BEFORE WIRING SHEET 07: U25-U28 pin 6 is currently wired onto the shared
TOF_3V3 rail. Delete the four long pin-6 wires to that rail. Leave pin 2 on
TOF_3V3. Give each pin 6 its own short wire to its TOF_n_SCL port, then use
Highlight Net to verify that each SCL stays separate from 3.3 V and the other SCLs.

POWER, PHY, AND HARDWARE-ONLY NETS
---------------------------------
WALL_19V_IN   -> Planned 19 V DC brick positive input before F_WALL
VWALL         -> Planned protected wall feed after F_WALL, to wall ORing
VBAT          -> Sheet 01 battery feed
MOTOR_BUS_RAW -> Battery-only protected feed for sheet 03
LV_OR_RAW     -> Combined battery/wall supply before the run switch
LV_RUN_RAW    -> Switched supply feeding the board's converters
LV_RUN_EN     -> U4 LM74800 EN/UVLO pad 6, driven by the RUN/OFF circuit
+12V          -> Regulated 12 V converter output
LOGIC_5V      -> Regulated 5 V logic supply
ANGLE_3V3     -> Angle-sensor header power
IMU_3V3       -> IMU header power
TOF_3V3       -> ToF header power
ETH_3V3A      -> Ethernet analog supply
ETH_TX_P/N, ETH_RX_P/N, KETH_TX_P/N, KETH_RX_P/N -> Ethernet pairs
XTAL1, XTAL2  -> PHY oscillator on sheet 08
ETH_CABLE_TERM, ETH_SHIELD, RJ4/5, RJ7/8 -> Cable-side Ethernet circuitry

Wall brick, positive wire  -> J_WALL (+) -> WALL_19V_IN -> F_WALL -> VWALL
Wall brick, negative wire  -> J_WALL (-) -> board power GND
J_WALL is the two-wire DC input. Verify polarity at the actual brick leads.
For an XT30 connection, C431092 is the PCB-side male and C99102 is the
female plug that goes on the brick's two wires.
In the saved drawing, VWALL is on the input side of F_WALL. When you add
J_WALL, name that input side WALL_19V_IN and move VWALL to the fused side.
